## 목적

/install-github-app 슬래시 명령어는 Claude Code 터미널 안에서 실행하는 명령어 입니다.

Claude Code 터미널 안에서 `/install-github-app` 명령어를 사용하면, GitHub 저장소(repository)에 Claude GitHub App을 설치하고 `@claude` 멘션으로 이슈나 PR에서 Claude를 호출할 수 있게 됩니다. 

구체적으로는:

- 이미 API 키가 있으면 그걸 재사용하거나, 리포지토리에 이미 설정된 ANTHROPIC_API_KEY 시크릿을 그대로 쓸지 물어봅니다. 없으면 Claude 구독으로 장기 토큰을 새로 만들거나 API 키를 직접 입력하는 방식 중 선택하게 됩니다. 

- 이 인증 정보를 리포지토리의 GitHub Secret으로 저장해줍니다.

설치하면 뭐가 좋아지나?

이걸 설치하면 GitHub Actions를 통해 리포지토리 안에서 직접 Claude를 호출할 수 있게 돼요. 예를 들면:

- PR이나 이슈 안에서 @claude라고 멘션하면 Claude가 자동으로 반응 (코드 질문 답변, 리뷰, 버그 수정 등)
- GitHub 호스팅 러너에서 자동으로 실행되고, 리포지토리를 신뢰 가능한 소스로 취급해서 작업 
- PR을 열 때마다 자동 코드 리뷰를 돌리거나, cron 스케줄로 정기 작업을 돌리는 것도 설정 가능
