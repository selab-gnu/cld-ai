# ADR-0001: 할 일 목록을 JSON 파일 하나에 저장한다

## 상태
승인

날짜: 2026-11-11

## 배경
할 일 목록은 프로그램을 다시 실행해도 유지되어야 한다(REQ-008). 이 앱은 교육용 예제로, 한 사람이 한 컴퓨터에서 쓰며 할 일은 많아야 수백 개다. 설치 없이 Node.js만으로 실행되어야 한다.

## 고려한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| JSON 파일 하나 | 설치 불필요, 파일을 열어 바로 확인 가능 | 동시에 여러 프로세스가 쓰면 마지막 쓰기만 남음, 항목이 많으면 느림 |
| SQLite | 동시 접근과 검색에 강함 | 네이티브 모듈 설치 필요 |
| 별도 DB 서버 | 여러 사용자 지원 | 실습 환경 준비가 무거움 |

## 결정
할 일 목록 전체를 JSON 파일 하나(기본 `todos.json`)에 저장하고, 변경할 때마다 파일 전체를 다시 쓴다. 파일 입출력은 `src/store.js`에만 둔다.

## 결과
- 좋은 점: 외부 의존성이 없고, 저장 내용을 사람이 직접 읽을 수 있다.
- 감수하는 점: CLI와 HTTP 서버가 동시에 쓰면 한쪽 변경이 사라질 수 있다. 여러 사용자 지원은 하지 않는다.
- 다시 검토할 조건: 여러 사용자가 동시에 쓰거나 할 일이 수천 개를 넘으면 SQLite 등으로 바꾸는 새 ADR을 쓴다. 저장 코드가 `store.js`에 모여 있으므로 교체 범위는 이 파일로 한정된다.
