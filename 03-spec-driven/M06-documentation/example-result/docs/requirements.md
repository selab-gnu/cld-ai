# 요구사항 목록

## 범위

할 일 관리 앱 `todo-app`의 사용자 관점 동작을 다룹니다. CLI(`src/cli.js`)와 HTTP API(`src/app.js`) 두 가지 사용 방법을 모두 포함합니다.
사용자 인증, 여러 사용자 동시 사용, 할 일 수정·정렬은 다루지 않습니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 할 일 | 번호(`id`), 제목(`title`), 완료 여부(`done`)로 이루어진 항목 |
| 번호 | 할 일을 가리키는 1 이상의 정수. 사용자가 완료·삭제할 때 쓴다. 삭제된 번호는 다시 쓰일 수 있다([ADR-0002](adr/0002-hard-delete.md)) |
| 저장 파일 | 할 일 목록을 담는 JSON 파일. 기본값은 `todos.json` |
