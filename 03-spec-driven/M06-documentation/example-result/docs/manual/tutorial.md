# 튜토리얼: 처음 사용하기

할 일 두 개를 추가하고, 하나를 완료 처리한 뒤 목록을 확인합니다.

## 준비

Node.js 22 이상이 필요합니다. `todo-app` 폴더에서 터미널을 엽니다.

## 1. 빈 목록 확인하기

```bash
node src/cli.js list
```

```
할 일이 없습니다.
```

## 2. 할 일 추가하기

```bash
node src/cli.js add 우유 사기
node src/cli.js add 책 읽기
```

명령마다 `추가했습니다.`가 출력됩니다. 제목은 따옴표 없이 띄어 써도 됩니다.

## 3. 완료 처리하기

```bash
node src/cli.js done 1
```

```
완료 처리했습니다.
```

## 4. 목록 다시 보기

```bash
node src/cli.js list
```

```
[x] 1. 우유 사기
[ ] 2. 책 읽기
```

`[x]`는 완료, `[ ]`는 미완료입니다. 할 일은 같은 폴더의 `todos.json`에 저장되므로 터미널을 닫았다 열어도 남아 있습니다.
