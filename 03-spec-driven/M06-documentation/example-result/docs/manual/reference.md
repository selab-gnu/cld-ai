# 레퍼런스

## CLI 명령

형식: `node src/cli.js <명령> [인자]`

| 명령 | 인자 | 동작 | 성공 출력 |
|---|---|---|---|
| `add` | 제목 (띄어쓰기 허용) | 할 일을 미완료 상태로 추가 | `추가했습니다.` |
| `done` | 번호 | 해당 할 일을 완료 처리 | `완료 처리했습니다.` |
| `remove` | 번호 | 해당 할 일을 목록에서 삭제 (복구 불가) | `삭제했습니다.` |
| `list` | 없음 | 전체 목록 출력 (`[x] 1. 제목` 형식) | 목록 또는 `할 일이 없습니다.` |
| (그 밖) | | 사용법 출력 | `사용법: node src/cli.js <add 제목 \| done 번호 \| remove 번호 \| list>` |

## 환경 변수

| 이름 | 기본값 | 쓰는 곳 | 뜻 |
|---|---|---|---|
| `TODO_FILE` | `todos.json` | CLI, 서버 | 저장 파일 경로 |
| `PORT` | `3000` | 서버 | HTTP 서버 포트 |

## HTTP API 요약

| 메서드와 경로 | 동작 | 성공 |
|---|---|---|
| `GET /todos` | 목록 조회 | 200 |
| `POST /todos` | 할 일 추가 (본문 `{"title": "..."}`) | 201 |
| `POST /todos/{id}/done` | 완료 처리 | 200 |
| `DELETE /todos/{id}` | 삭제 | 204 |

상세 명세: [openapi.yaml](../api/openapi.yaml)

## 오류 메시지

| 메시지 | 언제 | CLI 종료 코드 | API 상태 / `error.code` |
|---|---|---|---|
| 제목은 비어 있을 수 없습니다. | 제목이 비어 있거나 공백뿐 | 1 | 400 / `EMPTY_TITLE` |
| 번호는 1 이상의 정수여야 합니다. | 완료·삭제할 번호가 숫자가 아니거나 0 이하, 소수 | 1 | 400 / `INVALID_ID` |
| N번 할 일을 찾을 수 없습니다. | 없는 번호를 완료 처리하거나 삭제 | 1 | 404 / `NOT_FOUND` |
| 요청 본문이 올바른 JSON이 아닙니다. | API 요청 본문이 JSON이 아님 | — | 400 / `INVALID_JSON` |
| 경로를 찾을 수 없습니다. | 없는 API 경로 | — | 404 / `ROUTE_NOT_FOUND` |
