# M01 예제 실행 및 프롬프트 — 5분 Hello World

> 전제: [GUIDE.md](./GUIDE.md) 1단계(설치)를 마쳤다.
> 아래 프롬프트를 **그대로 복사해서** 붙여 넣으면 됩니다.

---

## 1단계: 연습 폴더 만들기

```bash
$ mkdir hermes-hello
$ cd hermes-hello
```

## 2단계: Hermes 실행

```bash
$ hermes
```
배너가 뜨고 입력 프롬프트가 나오면 준비 완료입니다.

## 3단계: 프롬프트가 뜨면 자연어로 지시

순서대로 하나씩 입력합니다. 각 프롬프트 아래는 **기대 결과**입니다. (모델에 따라 표현은 조금 다를 수 있습니다.)

### ① 인사하기
```text
안녕! "Hello, World!"라고 한 줄로만 대답해줘.
```
→ `Hello, World!`

### ② 파일 만들기
```text
현재 폴더에 hello.py 파일을 만들어줘. 실행하면 "Hello, Hermes!"를 출력하게 해줘.
```
→ `hello.py`를 만들었다는 답변

### ③ 직접 실행하기
```text
방금 만든 hello.py를 실행해서 결과를 보여줘.
```
→ 에이전트가 터미널 명령을 실행하고 `Hello, Hermes!` 출력 (승인을 물으면 허용)

### ④ 조금 바꿔 보기
```text
hello.py를 수정해서 이름을 입력받고 "Hello, <이름>!"을 출력하게 바꿔줘. 그리고 이름을 Hermes로 넣어서 테스트해줘.
```
→ 수정된 코드와 `Hello, Hermes!` 테스트 결과

### ⑤ 폴더 확인하기
```text
지금 폴더에 어떤 파일이 있는지 보여주고, 각 파일이 무엇인지 한 줄씩 설명해줘.
```
→ `hello.py` 목록과 설명

### ⑥ 기억시키기
```text
기억해줘: 내 이름은 선아이고, 답변은 항상 한국어로 짧게 해줘.
```
이어서 새 대화로 확인합니다.
```text
/new
```
```text
내 이름이 뭐야?
```
→ `선아님이에요.`

### ⑦ 종료
```text
/quit
```

## 4단계: 결과 확인하기

터미널에서 직접 확인합니다.

```bash
$ ls
hello.py

$ python3 hello.py              # Windows는 python hello.py

$ cat ~/.hermes/memories/USER.md   # 기억된 내용 보기
```

## 5단계: 지난 대화 이어서 하기 (보너스)

```bash
$ hermes -c
```
```text
아까 만든 hello.py에 주석을 한국어로 달아줘.
```

---

## 완료 체크리스트

- [ ] ① 에이전트가 `Hello, World!`라고 답했다.
- [ ] ②③ `hello.py`가 생기고 실행 결과를 봤다.
- [ ] ④ 에이전트가 코드를 수정하고 테스트했다.
- [ ] ⑥ `/new` 후에도 내 이름을 기억했다.
- [ ] 5단계의 `hermes -c`로 지난 대화를 이어서 했다.
