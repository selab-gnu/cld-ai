# 모듈 — LangGraph — 하니스 엔지니어링

> 상태: 초안 · 담당: 이선아 교수

## 목적

.claude 폴더에 에이전트와 스킬을 만들어 Claude Code를 위한 하네스 엔지니어링을 만드는 방법을, **LangGraph**라는 실제 프레임워크를 예시로 배워본다. [LangGraph](https://github.com/langchain-ai/langgraph)는 LLM 애플리케이션을 State·Node·Edge로 이루어진 그래프로 모델링하는 파이썬/JS 라이브러리로, 사이클(반복)을 지원해 도구 호출, 조건부 분기, 대화 기억을 갖춘 상태 기반 에이전트를 만드는 데 쓰인다. 이 모듈에서는 초보자가 State/Node/Edge 개념을 이해하고, 첫 그래프를 직접 만들고, 도구와 조건부 라우팅을 붙이고, 체크포인터로 대화를 기억시키고, 로컬에서 그래프를 시각화·관찰하기까지의 흐름을 GUIDE.md → SAMPLE.md 순서로 실습한다.

## 산출물 4종 (체크리스트)

- [x] 가이드 — GUIDE.md: 사전 준비 → 설치 → State/Node 정의 → 첫 그래프 실행 → 도구·조건부 라우팅 → 체크포인터(메모리) → 시각화/로컬 관찰까지 7단계, 단계별 규칙·산출물·체크리스트 포함
- [ ] 규칙 — CLAUDE.md 조각 (어시스턴트가 LangGraph 코드를 작성/리뷰할 때 지킬 규칙; 예: 상태는 항상 TypedDict로 정의하고 리듀서를 명시할 것, 노드는 상태 전체가 아니라 변경분만 반환할 것, 체크포인터 없이 멀티턴 대화를 구현하지 말 것 — 아직 별도 조각으로 정리되지 않음)
- [ ] 자동화 — 스킬·서브에이전트 (예: `/langgraph-scaffold` 같은 스킬로 State/Node/Edge 보일러플레이트를 자동 생성하거나, 그래프 구조를 검토하는 서브에이전트 — 아직 만들지 않음)
- [x] 샘플 — SAMPLE.md: GUIDE.md로 만든 그래프를 실제로 실행·대화·시각화하는 동작 스텝과 프롬프트

## 품질 기준

동작하는 샘플 또는 재현 가능한 프롬프트가 반드시 첨부되어야 하며, 문서는 따라 하면 되는 수준이어야 한다. LangGraph 코드는 실습 환경에서 최소 한 번 `invoke`까지 실행되어 실제 응답으로 확인된 것이어야 한다.
