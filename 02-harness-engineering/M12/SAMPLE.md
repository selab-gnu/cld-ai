# 예제 실행 및 프롬프트

`ralph-demo-task` 저장소의 결과물인 브라우저 기반 Todo 앱을 로컬에서 실행하는 방법을 단계별로 안내합니다. 백엔드도 빌드 과정도 없는 순수 ES 모듈 앱이며, 할 일 데이터는 브라우저의 `localStorage`에 저장됩니다.

## 0단계: 사전 준비

- **Python 3** (정적 서버 실행용, `npm run serve`가 내부적으로 사용) — 또는 원하는 다른 정적 서버
- **Node.js** (테스트 실행 시에만 필요, 앱을 그냥 보기만 할 거라면 없어도 됨)
- 최신 브라우저 (Chrome, Safari, Firefox 등 — ES 모듈을 지원하면 무엇이든 가능)

버전 확인:

```bash
python3 --version
node --version
```

## 1단계: 정적 서버 실행

```bash
cd .../ralph-demo-task
```

이 앱은 `<script type="module">`을 쓰기 때문에 `file://`로 `index.html`을 직접 열면 브라우저가 모듈 로드를 막습니다. 반드시 `http://`로 접근해야 하므로 정적 서버를 하나 띄웁니다.

```bash
npm run serve
```

이 명령은 `package.json`에 정의된 대로 내부적으로 다음을 실행합니다.

```bash
python3 -m http.server 8000
```

터미널에 아래와 같은 로그가 보이면 정상적으로 떠 있는 상태입니다.

```
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

이 터미널 창은 서버가 떠 있는 동안 계속 열어 두어야 합니다.

## 2단계: 브라우저에서 열기

브라우저 주소창에 다음 주소를 입력합니다.

```
http://localhost:8000
```

`Todo` 제목과 함께 할 일 추가 폼, 우선순위 필터, 정렬 체크박스, 빈 목록 안내 문구가 보이면 정상적으로 실행된 것입니다.

## 3단계: 앱 둘러보기

- **할 일 추가**: 상단 입력창에 내용을 입력하고 우선순위(`Priority`)를 선택한 뒤 `Add`를 누릅니다.
- **우선순위 바꾸기**: 목록에 있는 각 항목의 우선순위 배지(뱃지)를 클릭하면 낮음 → 보통 → 높음 순으로 우선순위가 바로 바뀝니다.
- **수정**: 항목의 `Edit`를 누르면 제목과 우선순위를 고칠 수 있는 편집 폼이 열립니다. `Save`로 저장하거나 `Cancel`로 취소합니다.
- **삭제**: 항목의 `Delete`를 누르면 목록에서 제거됩니다.
- **필터**: 상단의 `Priority` 드롭다운(목록 헤더 쪽)으로 특정 우선순위만 걸러 볼 수 있습니다. 필터로 인해 가려진 항목이 있으면 몇 개가 숨어 있는지 안내 문구로 알려줍니다.
- **정렬**: `Sort by priority` 체크박스를 켜면 높은 우선순위부터 정렬되어 보입니다(저장된 순서 자체는 바뀌지 않고, 체크를 끄면 원래 순서로 돌아옵니다).

새로고침하거나 브라우저를 껐다 켜도 `localStorage`에 저장된 내용은 그대로 유지됩니다.

## 4단계: 서버 종료

다 확인했다면 서버를 띄운 터미널 창에서 `Ctrl + C`를 눌러 종료합니다.

## (선택) 데이터 초기화하기

할 일 데이터를 깨끗하게 지우고 처음 상태로 보고 싶다면:

1. 브라우저 개발자 도구를 엽니다(`F12` 또는 `Cmd+Option+I`).
2. `Application`(또는 `저장공간`) 탭 → `Local Storage` → `http://localhost:8000` 항목을 선택합니다.
3. 관련 키(할 일 데이터/보기 설정)를 삭제하고 페이지를 새로고침합니다.

또는 브라우저의 시크릿/프라이빗 창에서 열면 매번 빈 상태로 시작할 수 있습니다.

## (선택) 테스트 실행하기

앱 코드가 아니라 코드가 제대로 동작하는지 확인하고 싶다면 Node.js 테스트를 실행할 수 있습니다.

```bash
npm test
```

`node:test` 기반 테스트가 실행되며, 실패하는 테스트가 있으면 종료 코드가 0이 아닌 값으로 끝납니다.

문법 검사만 빠르게 하고 싶다면(타입체크나 린트는 아님):

```bash
npm run check:syntax
```

## 문제 해결

| 증상 | 원인 / 해결 방법 |
|---|---|
| 화면이 하얗게 뜨고 아무것도 안 보임, 콘솔에 모듈 관련 에러 | `index.html`을 더블클릭해서 `file://`로 열었을 가능성이 큽니다. 반드시 `npm run serve`로 띄운 뒤 `http://localhost:8000`으로 접속하세요. |
| `Address already in use` 등 포트 충돌 에러 | 8000번 포트를 다른 프로그램이 쓰고 있습니다. `python3 -m http.server 8001`처럼 다른 포트로 직접 띄우고 `http://localhost:8001`로 접속하세요. |
| 할 일을 추가해도 새로고침하면 사라짐 | 브라우저의 시크릿 모드이거나 사이트 데이터 차단 설정이 켜져 있을 수 있습니다. 일반 창에서, 그리고 localStorage를 허용한 상태에서 다시 시도하세요. |
| `npm test`가 `command not found` 등으로 실패 | Node.js가 설치되어 있지 않은 환경입니다. 테스트는 앱 실행에 필수가 아니므로 건너뛰어도 됩니다. |
