# 모듈 — — 기존에 만들어진 하네스 활용

> 상태: 초안 · 담당: 이선아 교수

## 목적

참조 깃허브 링크에서 기존에 만들어진 하네스를 활용하는 법을 배운다. .claude 폴더에 기존에 만들어진 에이전트와 스킬을 복사하여 Claude Code를 활용한 실습을 진행한다.

## 치트시트

```bash
# 1. 폴더 만들기
mkdir my-research && cd my-research

# 2. 하네스 받기
git clone --depth 1 https://github.com/revfactory/harness-100.git /tmp/h100
cp -r /tmp/h100/ko/63-research-assistant/.claude ./

# 3. 실행
claude

# 4. 요청 (Claude Code 안에서)
# > '주제'에 대한 문헌 리뷰를 해줘. APA 형식으로.

# 5. 결과 확인
# _workspace/ 폴더의 01~05 마크다운 파일
```

## 산출물 4종 (체크리스트)

- [x] 가이드 — GUIDE.md 단계 목적·입력·산출물·체크리스트
- [X] 규칙 — CLAUDE.md 조각은 .claude 폴더 하에 존재하며 하네스의 구성 에이전트와 스킬 나열
- [x] 자동화 — .claude 폴더 하에 존재하는 스킬과 에이전트 존재
- [x] 샘플 — SAMPLE.md 동작 스텝·프롬프트

## 품질 기준

동작하는 샘플 또는 재현 가능한 프롬프트가 반드시 첨부되어야 하며, 문서는 따라 하면 되는 수준이어야 한다.

- 가이드에서는 이론적인 내용을 포함하여 개념과 따라가기가 함께 되는 수준이어야 한다.
- 샘플은 가이드에서 만든 결과를 활용할 수 있는 재현 가능한 프롬프트가 반드시 첨부되어야 하며, 따라 하면 되는 수준이어야 한다.
- 자동화는 활용 폴더에 이미 올려 둔다.

## 트러블 슈팅

**Q. `/research-assistant`를 입력해도 스킬이 안 뜹니다.**

`.claude` 폴더가 현재 폴더 바로 아래에 있는지 확인하세요 (`ls -a`로 확인). `my-research/63-research-assistant/.claude`처럼 한 단계 더 들어가 있으면 인식되지 않습니다. Claude Code를 재시작(`exit` 후 다시 `claude`)해 보세요.

**Q. 검색 결과가 너무 적게 나옵니다.**

주제가 매우 좁으면 인접 분야로 확대 검색하고 "예비 검색"이라고 표시해 줍니다. 검색어를 영어로 바꾸거나 주제를 조금 넓혀 다시 요청해 보세요.

**Q. 논문 전문을 못 가져왔다고 나옵니다.**

유료 저널은 접근이 안 되므로 초록 기반으로 작업하고 "전문 미확인"으로 표시합니다. 정상 동작입니다. 원문은 소속 기관 도서관 등에서 직접 확인하세요.

**Q. 시간이 너무 오래 걸립니다.**

풀 파이프라인은 웹 검색 + 5개 에이전트 작업이라 원래 오래 걸립니다. 급하면 "검색 모드"부터 돌려서 문헌 목록만 먼저 받고, 이후 단계를 나눠 요청하세요.

**Q. 결과물 중 일부가 누락됐습니다.**

에이전트가 실패하면 1회 재시도 후 해당 산출물 없이 진행하고 최종 보고서(`05_research_summary.md`)에 누락 사실을 명시합니다. 해당 파일만 다시 만들어 달라고 요청하면 됩니다.
