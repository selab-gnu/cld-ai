# 모듈 — Claude Code 훅(Hook) 입문

> 상태: 초안

## 목적

초보자가 Claude Code의 "훅(Hook)" 기능을 이해하고, 직접 하나 만들어서 동작을 확인해본다.

## 훅(Hook)이 뭔가요?

Claude Code는 코드를 수정하거나 명령어를 실행하는 등 여러 작업을 자동으로 한다. 훅은 "이 작업 전/후에 내가 정한 명령어를 무조건 실행해줘"라고 등록해두는 기능이다. CLAUDE.md에 규칙을 적어두면 Claude가 "대체로" 따르지만, 훅으로 등록하면 매번 확실하게 실행된다.

예: "파일을 수정할 때마다 자동으로 포맷팅해줘", "Claude가 내 입력을 기다릴 때 데스크톱 알림을 보내줘", "`.env` 파일은 절대 수정하지 못하게 막아줘" 같은 것들이 모두 훅으로 구현 가능하다.

## 무엇을 만드나요?

- Claude가 내 입력을 기다릴 때 데스크톱 알림을 보내주는 `Notification` 훅 (가장 기본, 설치 없이 바로 테스트 가능)
- (심화) 파일을 수정할 때마다 자동으로 포맷팅하는 `PostToolUse` 훅

## 산출물 4종 (체크리스트)

- [x] 가이드 — GUIDE.md 단계별 목적·규칙·산출물·체크리스트
- [ ] 규칙 — CLAUDE.md 조각 (이 모듈에서는 해당 없음, 훅 자체가 규칙 역할)
- [x] 자동화 — SAMPLE.md에 포함된 재사용 가능한 settings.json 예시
- [x] 샘플 — SAMPLE.md 동작 스텝·프롬프트

## 품질 기준

- 실제로 Claude Code에서 동작을 눈으로 확인할 수 있어야 한다 (알림이 뜨는지, 파일이 포맷팅되는지).
- 코드를 몰라도 `settings.json`에 붙여넣기만 하면 동작해야 한다.
- 각 단계마다 "제대로 등록됐는지 확인하는 방법(체크리스트)"이 있어야 한다.

## 사전 준비물

- Claude Code가 설치되어 있고 터미널에서 `claude` 명령어로 실행 가능한 상태
- 텍스트 편집기 (VS Code 권장)
- (심화 단계용) `jq` 설치 — macOS는 `brew install jq`, Ubuntu/Debian은 `apt-get install jq`
