# 모듈 — Todo 앱으로 배우는 Claude Code 하네스 엔지니어링

> 상태: 완료 · 예제: Todo 앱(Python CLI)

## 목적

`.claude` 폴더에 규칙(CLAUDE.md)과 자동화(Hook)를 만들어, Claude Code가 "부탁받은 대로"가 아니라 "정해진 대로" 동작하게 만드는 하네스 엔지니어링을 아주 작은 예제로 실습한다.

## 전체 과정 요약

1. **예제 프로젝트 준비** — `add`, `list`만 되는 최소 기능 Todo 앱(`todo.py`)을 만든다.
2. **Claude Code 연결** — 프로젝트 루트에 `.claude/settings.json`을 만들어 프로젝트 전용 설정 공간을 확보한다.
3. **규칙 정의** — `CLAUDE.md`에 "todo.json은 직접 수정 금지", "출력 형식 유지", "수정 후 직접 실행해서 확인" 같은 규칙을 적는다.
4. **Hook 설계** — 어떤 이벤트(PostToolUse/PreToolUse)에 어떤 액션을 걸지 표로 먼저 정리한다.
5. **자동 포맷팅 Hook 구현** — 파일을 고칠 때마다 `black`으로 스타일을 정리하고 `todo.py list`로 자동 확인하는 Hook을 붙인다.
6. **안전장치 Hook 추가** — `todo.json`을 지우거나 덮어쓰는 위험한 Bash 명령을 무조건 차단하는 Hook을 붙인다.
7. **검증 및 문서화** — Claude에게 실제로 `complete` 기능을 추가시켜보고, 그 프롬프트와 결과를 `SAMPLE.md`에 그대로 기록한다.

핵심은 이거예요: **프롬프트는 무시될 수 있지만 Hook은 조건만 맞으면 항상 실행된다.** 그래서 "매번 사람이 확인하던 반복 작업"만 골라 Hook으로 옮기는 게 이 과정의 목표입니다.

## 산출물 4종 (체크리스트)

- [x] 가이드 — [`GUIDE.md`](./GUIDE.md): 7단계별 목적·규칙·산출물·체크리스트
- [x] 규칙 — `GUIDE.md` 3단계에 포함된 `CLAUDE.md` 조각
- [x] 자동화 — `GUIDE.md` 5·6단계에 포함된 `.claude/settings.json` (PostToolUse 포맷팅 Hook, PreToolUse 위험 명령 차단 Hook)
- [x] 샘플 — [`SAMPLE.md`](./SAMPLE.md): 실제로 재현 가능한 동작 스텝·프롬프트

## 사용 방법

1. `GUIDE.md`를 1단계부터 순서대로 따라간다.
2. 각 단계의 "산출물" 코드 블록을 그대로 복사해서 파일로 만든다.
3. 각 단계의 "체크리스트"를 직접 실행해서 눈으로 확인한다.
4. 7단계까지 끝나면 `SAMPLE.md`에 적힌 프롬프트를 그대로 입력해 전체 흐름(수정 → 자동 포맷팅 → 자동 확인 → 위험 명령 차단)이 실제로 동작하는지 검증한다.

## 품질 기준

동작하는 샘플(`SAMPLE.md`)과 재현 가능한 프롬프트가 반드시 첨부되어야 하며, `GUIDE.md`만 보고 따라 해도 동일한 결과가 나와야 한다. 이 모듈은 위 기준을 모두 충족한다.
