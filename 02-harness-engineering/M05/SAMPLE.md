# 예제 실행 및 프롬프트

## 1단계: 실제 서베이 작업 지시

팀 구성이 끝났다면 이제 실제 조사·작성 작업을 지시합니다.

```
Neuro-Symbolic AI 서베이를 진행해줘. 최근 3~5년 연구 동향, 대표적인 접근법 분류,
주요 논문/시스템, 남은 과제를 포함해서 초안을 작성하고 검수까지 마쳐줘.
```

Pipeline 구조라면 researcher → analyst → writer → reviewer 순으로 작업이 이어지며, 각 단계의 산출물을 다음 에이전트가 이어받아 작업합니다. 중간에 진행 상황과 각 에이전트의 산출물을 확인할 수 있습니다.

## 2단계: 최종 결과물을 Word 문서로 받기

초안이 완성되면 아래처럼 요청해 최종본을 .docx 파일로 정리하도록 합니다.

```
최종 서베이 보고서를 워드 문서(.docx)로 저장해줘. 목차, 제목 스타일, 참고문헌 목록을 포함해줘.
```

writer(또는 별도 formatting) 에이전트가 문서 생성 스킬을 이용해 .docx 파일을 만들고, 완료되면 다운로드/열람 가능한 파일 경로를 알려줍니다.
