# 예제 실행 및 프롬프트

## 1단계: 개발 서버 실행

터미널에서 프로젝트 폴더로 이동한 뒤 개발 서버를 실행합니다.
```bash
cd my-counter-app
npm run dev
```

터미널에 아래와 비슷한 로컬 주소가 표시됩니다.
```
Local:   http://localhost:5173/
```

## 2단계: 브라우저에서 결과 확인

브라우저에서 `http://localhost:5173/` 주소로 접속합니다.

- "+1 증가" 버튼을 눌러 숫자가 1씩 올라가는지 확인합니다.
- 숫자가 5 이상이 되면 안내 문구가 바뀌는지 확인합니다.
- "초기화" 버튼을 눌러 숫자가 0으로 돌아가는지 확인합니다.

정상적으로 동작하면 튜토리얼이 완료된 것입니다. 이후에는 컴포넌트를 추가하거나 스타일을 자유롭게 바꿔보며 React에 익숙해져 보세요.
