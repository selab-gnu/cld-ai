# 모듈 — Supabase 데이터베이스 입문

> 상태: 초안

## 목적

초보자가 Supabase를 이용해 아주 간단한 데이터베이스(할 일 목록 앱)를 만들고, 데이터를 저장·조회하는 전체 흐름을 직접 경험해본다.

## 무엇을 만드나요?

- Supabase 프로젝트 생성 (회원가입 ~ 데이터베이스 생성)
- `todos`라는 테이블 하나 만들기
- 설치 없이 브라우저에서 바로 실행되는 `index.html` 하나로, 할 일을 추가하고 목록을 불러오는 기능 구현
- 기본적인 보안 설정(RLS)까지 확인

코딩 경험이 거의 없어도, GUIDE.md의 단계를 순서대로 따라가면 완성할 수 있도록 구성했다.

## 산출물 4종 (체크리스트)

- [x] 가이드 — GUIDE.md 단계별 목적·규칙·산출물·체크리스트
- [ ] 규칙 — CLAUDE.md 조각 (이 모듈에서는 해당 없음)
- [x] 자동화 — SAMPLE.md에 포함된 재사용 가능한 예제 코드
- [x] 샘플 — SAMPLE.md 동작 스텝·프롬프트

## 품질 기준

- 실제로 브라우저에서 동작하는 예제 코드가 첨부되어야 한다.
- 코드를 몰라도 복사·붙여넣기만으로 결과를 볼 수 있어야 한다.
- 각 단계마다 "성공했는지 확인하는 방법(체크리스트)"이 있어야 한다.

## 사전 준비물

- 이메일 계정 (Supabase 가입용, GitHub 계정으로도 가능)
- 웹 브라우저 (Chrome, Edge 등)
- 텍스트 편집기 (메모장도 가능, VS Code 권장)
- Node.js 설치는 필요 없음 (CDN 방식 사용)
