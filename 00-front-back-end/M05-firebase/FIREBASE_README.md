# 모듈 — Firebase 데이터베이스 입문

> 상태: 초안

## 목적

초보자가 Firebase(Cloud Firestore)를 이용해 아주 간단한 데이터베이스(할 일 목록 앱)를 만들고, 데이터를 저장·조회하는 전체 흐름을 직접 경험해본다.

## 무엇을 만드나요?

- Firebase 프로젝트 생성 (구글 계정으로 가입 ~ 프로젝트 생성)
- Cloud Firestore 데이터베이스 만들기
- `todos`라는 컬렉션(테이블과 비슷한 개념) 하나 사용하기
- 설치 없이 브라우저에서 바로 실행되는 `index.html` 하나로, 할 일을 추가하고 목록을 불러오는 기능 구현
- 기본적인 보안 설정(Security Rules)까지 확인

코딩 경험이 거의 없어도, GUIDE.md의 단계를 순서대로 따라가면 완성할 수 있도록 구성했다. Supabase 버전과 같은 "할 일 목록" 예제를 사용하므로, 두 서비스가 개념적으로 어떻게 다른지 비교해보기에도 좋다.

## Supabase와 무엇이 다른가요?

- Supabase는 관계형 데이터베이스(테이블, 행)이고, Firestore는 문서형 데이터베이스(컬렉션, 문서)다. 그래서 "테이블"이 아니라 "컬렉션", "행"이 아니라 "문서"라는 용어를 쓴다.
- Supabase는 SQL 기반, Firestore는 `collection()`, `addDoc()` 같은 함수 기반으로 데이터를 다룬다.
- 둘 다 웹페이지에서 직접 접속 가능한 백엔드 서비스라는 점, 보안 규칙으로 접근을 제어한다는 점은 동일하다.
